# **Web-crawler**

В данном репозитории представлен кроулер для сбора информации о товарах с веб страниц продовольственных магазинов. 

В качестве таргета был выбран [okeydostavka.ru](https://www.okeydostavka.ru/msk?storeId=10151&catalogId=10551)

Для парсинга сбора данных, эмуляции действий пользователя и проксирования трафика использовалась библиотека chromedp

Собранные для примера наборы данных расположены в [reports](./reports)
